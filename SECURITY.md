# Reporting a security vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/mushjacob/freestyle-studio-uis/security/advisories/new) once private reporting is enabled. If the form is unavailable, use the support channel in Freestyle to request a private reporting contact.

Include the affected view, the commit or version, the impact, and a sanitized description. Keep access tokens, signed URLs, and user project data out of reports and public issues.
